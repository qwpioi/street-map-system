🎨 设计方案说明

色彩系统

  • 主色 #FFD100 — 美团标志性黄色，用于头部、TabBar高亮、主按钮
  • 强调色 #FF6633 — 价格、评分、标签，营造食欲感
  • 成功色 #00C853 — 营业状态、距离信息
  • 警示色 #FF3366 — 排行榜渐变、退出按钮
  • 背景色 #F5F5F5 — 统一浅灰底色

核心变化 vs 当前版本

  • 首页头部：绿色渐变 → 美团黄色，增加定位信息+天气，搜索栏从独立变为嵌入式
  • 功能入口：大圆角渐变色方块 → 轻量圆形图标 + 更紧凑的 4×2 网格
  • 新增运营 Banner：橙红渐变促销横幅，增加视觉焦点和运营位
  • 摊位卡片：左图右文横排 → 保留但信息更丰富（评分星标、标签、营业状态小角标）
  • 快速状态条：新增横向滚动 chip，显示"附近N家营业中"等实时信息
  • 摊位详情：顶部增加黄色渐变背景+返回/分享按钮，信息改为 2×2 grid 布局
  • 底部操作栏：增加电话、收藏图标按钮 + 双主操作按钮（评价+导航）
  • 收藏页：增加顶部分类 Tab（全部/营业中/已收摊），卡片信息更紧凑
  • 个人中心：增加数据统计卡片（收藏/评价/常去/摊位数），增加"我的订单"快捷入口
  • Tab Bar：高亮色从绿色改为美团黄，保持统一品牌感

设计原则

  • 信息密度提升：美团风格的核心是"一屏展示更多信息"，通过更紧凑的间距和更小的字号实现
  • 视觉层次分明：黄色头部 → 白色内容区 → 浅灰背景，三层递进
  • 标签系统：每个摊位卡片最多展示 3 个标签（品类/人均/热门），用色彩区分类型
  • 状态即时可见：营业/收摊状态以小角标形式直接显示在缩略图上
  • 操作触手可及：导航、收藏按钮直接外露在卡片上，减少点击层级
