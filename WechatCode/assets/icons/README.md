# TabBar 图标资源

需要在此目录下放置以下 8 个 PNG 图标文件（建议尺寸 81×81px）：

## 首页
- `tab-home.png` - 首页图标（未选中，灰色 #999999）
- `tab-home-active.png` - 首页图标（选中，暖黄 #FFB300）

## 地图
- `tab-map.png` - 地图图标（未选中，灰色 #999999）
- `tab-map-active.png` - 地图图标（选中，暖黄 #FFB300）

## 收藏
- `tab-fav.png` - 收藏图标（未选中，灰色 #999999）
- `tab-fav-active.png` - 收藏图标（选中，暖黄 #FFB300）

## 我的
- `tab-profile.png` - 我的图标（未选中，灰色 #999999）
- `tab-profile-active.png` - 我的图标（选中，暖黄 #FFB300）

## 图标建议
- 格式：PNG（支持透明背景）
- 尺寸：81×81px（或 2x 图 162×162px）
- 风格：线性图标，线条粗细统一
- 推荐图标库：IconFont、Feather Icons、Material Icons

## 临时解决方案
如果暂时没有图标，可以先使用 emoji 文字代替，后续再补充图标资源。
